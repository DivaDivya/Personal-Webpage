# Divya Sinha Personal Webpage

## Run locally

1. Install Node.js 18+.
2. Open a terminal in this folder.
3. Run:
   npm install
   npm run dev
4. Open the local URL Vite prints.

## Before publishing

Replace the `#` placeholders in `src/main.jsx` with your GitHub and LinkedIn URLs.
Replace `your-email@example.com` with your email.
Place your resume PDF in the `public` folder as `Divya-Sinha-Resume.pdf`.

## Deploy

This Vite project can be deployed to Vercel, Netlify, or GitHub Pages.
